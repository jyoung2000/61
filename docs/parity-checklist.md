## Pixel-level verification

The table above is the feature-level contract. For pixel-level checks
between the client canvas export and the server FFmpeg export, run the
frame-compare harness on a machine with FFmpeg (e.g. the Unraid host):

```bash
python scripts/parity_harness.py client_export.mp4 server_export.mp4 \
    --timestamps 1.0 2.5 5.0 --ssim-threshold 0.90
```

It extracts frames at the given timestamps from both renders, reports
per-frame SSIM and subtitle bounding-box position/size deltas, and exits
non-zero when any frame falls below the threshold. Known acceptable
divergence sources: libass vs canvas font metrics (a few px), xfade
easing vs canvas cubic-bezier during transitions, and pitch handling of
speed changes (varispeed vs atempo — audio only).
